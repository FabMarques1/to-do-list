# 📝 | Lista de afazeres em Python

Uma aplicação simples e funcional de lista de tarefas via CLI, desenvolvida em Python. O projeto foca em organizar o dia a dia diretamente pelo terminal, aplicando conceitos fundamentais de programação e estrutura de dados.

## Funcionalidades

* **Adicionar tarefas:** Cadastre itens informando título e descrição.
* **Visualizar lista:** Exiba todas as tarefas organizadas e numeradas.
* **Interface limpa:** Navegação simples via menu interativo com limpeza automática de tela.

## Tecnologias Utilizadas

* **Python 3.11.9**
* **Módulo `os`** (para manipulação e controle do terminal)

## Conceitos Aplicados

* Estruturas de controle (`while`, `match/case`)
* Manipulação de coleções (Listas e Dicionários)
* Modularização do código com Funções
* Formatação dinâmica de strings
